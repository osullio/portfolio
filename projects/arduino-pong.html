Overview

A handheld Pong console built on an Arduino. The game draws on a 128×64 SSD1306 OLED and is played with an analog joystick against a bot that predicts where the ball will go.

Hardware

  • Arduino board, with pin 2 used as an interrupt for the joystick button
  • SSD1306 128×64 OLED over software SPI
  • Analog joystick (Y axis for the paddle, push-button to serve)
Wiring diagram (Fritzing export) and a photo of the console

How it works

  • Game loop: each frame clears the buffer, reads input, moves both paddles, checks collisions, moves the ball and pushes the frame to the display.
  • Input: the joystick button is caught by a hardware interrupt, so the game never misses a serve. The Y axis has a dead zone so the paddle doesn't drift.
  • Bot: works out where the ball will reach its paddle from the ball's slope (targetY = slope · Δx + ballY) and moves toward that point at a capped speed, so steep shots can still beat it.
  • Scaling: paddle and ball sizes are calculated from the screen size, not hard-coded, so the game adapts to other displays.
  • Structure: a Ball class, display setup in its own header, and game logic split across separate files.
